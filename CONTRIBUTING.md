# Contributing

Bugs, odd edge cases, one-line fixes, new cookies, ideas and complaints are all welcome. Open an issue or a pull
request. Every one gets a reply.

The most useful reports right now:

- A browser, GPU or phone where the backdrop stutters, renders black or looks wrong. Include the tag you used.
- A cookie image that comes out wrong, attached.
- A lighting gag from film or stage that the rig could do. The README has a list. Add to it.

For code, read [DEVELOPMENT.md](DEVELOPMENT.md) first. It is short. Keep pull requests small and say why the change
matters in the description. There is no template.

**Found something broken? Open an issue today.**
